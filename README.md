## 👨‍💻 About Me

<img align="right" width="300" src="https://raw.githubusercontent.com/Joshndeule/Joshndeule/main/profile-summary-card-output/tokyonight/0-profile-details.svg" alt="" />

I'm an **ICT professional** from **Lilongwe, Malawi** who builds scalable full‑stack applications with clean, maintainable architecture — and brings the same rigor to analysing modern network infrastructure.

My work sits at the intersection of **software engineering** and **network & security fundamentals**: from relational schemas and REST APIs to Cisco topologies and defensive best practices.

- 💼 **Full‑Stack Developer Intern** at **INFI‑TECH** — Next.js, NestJS & TypeScript
- 🎓 **BSc in ICT** — Mzuzu University *(2021 – 2026)*
- 🏗️ Currently building **SaaS Systems** platforms with **microservices** behind an API gateway
- 🌐 Designing & simulating networks with **Cisco Packet Tracer**
- 🔒 Interested in **Cybersecurity, AI and Networking**
- 💬 Ask me about **NestJS, PostgreSQL schema design, or VLANs**
